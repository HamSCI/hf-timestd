Key Data Models (Shared Across All Functions):

┌─────────────────────────────────────────────────────────────────────────┐
│ SampleBatch - Primary data container                                    │
│   • timestamp, samples, sample_rate                                     │
│   • quality: QualityInfo                                                │
│   • time_snap: TimeSnapReference                                        │
│   • channel_name, frequency_hz, ssrc                                    │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ QualityInfo - Quality metrics                                           │
│   • completeness_pct, gap_count, packet_loss_pct                        │
│   • discontinuities: List[Discontinuity]                                │
│   • quality_grade: A/B/C/D/F                                            │
│   • time_snap_established, time_snap_confidence                         │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ TimeSnapReference - KA9Q timing anchor                                  │
│   • rtp_timestamp, utc_timestamp, sample_rate                           │
│   • source: 'wwv_verified', 'chu_verified', 'initial'                   │
│   • station: 'WWV', 'CHU', 'initial'                                    │
│   • calculate_sample_time(rtp_ts) → utc_time                            │
│                                                                          │
│   Formula: utc = time_snap_utc + (rtp - time_snap_rtp) / sample_rate   │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ ToneDetectionResult - WWV/WWVH discrimination                       │
│   • station: StationType (WWV | WWVH | CHU)                             │
│   • frequency_hz: 1000 or 1200                                          │
│   • timing_error_ms, snr_db, confidence                                 │
│   • use_for_time_snap: bool  ⚠️ CRITICAL                                │
│                                                                          │
│   WWV (1000 Hz):  use_for_time_snap = True  (timing reference)         │
│   WWVH (1200 Hz): use_for_time_snap = False (propagation study only)   │
│   CHU (1000 Hz):  use_for_time_snap = True  (timing reference)         │
└─────────────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│ Discontinuity - Gap/jump record for scientific provenance              │
│   • timestamp, sample_index                                             │
│   • discontinuity_type: GAP | RTP_RESET | SYNC_ADJUST | ...            │
│   • magnitude_samples, magnitude_ms                                     │
│   • rtp_sequence_before/after, rtp_timestamp_before/after               │
│   • wwv_related: bool, explanation: str                                 │
└─────────────────────────────────────────────────────────────────────────┘

Interface Methods Summary:

Function 1: QualityAnalyzedSampleProvider
  • get_sample_batch() → SampleBatch
  • get_time_snap_reference() → TimeSnapReference
  • get_discontinuities(since) → List[Discontinuity]
  • get_quality_summary() → QualityInfo
  • register_time_snap_update_callback(callback)

Function 2: ArchiveWriter
  • write_samples(timestamp, samples, quality, time_snap) → Optional[Path]
  • add_discontinuity(discontinuity)
  • flush() → Optional[Path]
  • verify_file_integrity(path) → bool

Function 3: ToneDetector
  • process_samples(timestamp, samples) → List[ToneDetectionResult]
  • get_differential_delay() → float (WWV - WWVH)
  • set_detection_threshold(threshold)

Functions 4+5: DecimatorWriter
  • write_decimated(timestamp, samples, quality, time_snap) → Optional[Path]
  • get_decimation_factor() → int (1600 = 16000/10)
  • embed_quality_metadata(quality, discontinuities)
  • flush() → Optional[Path]

Function 6: UploadQueue
  • queue_file(local_path, metadata, priority) → task_id
  • get_task_status(task_id) → UploadTask
  • get_pending_count() → int
  • retry_failed_tasks() → int
  • set_bandwidth_limit(kbps)
