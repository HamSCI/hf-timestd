# Archived I/Q in F16 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** hf-timestd and meteor-scatter store archived I/Q as F16 (scaled by 2¹²) on the station, behind a per-station setting, while every reader and every export still gets F32.

**Architecture:** One small codec (encode F32→F16 bytes with a fixed scale, decode bytes→complex64 by sidecar dtype and scale) lives in hf-timestd; hamsci-physics and meteor-scatter carry a copy, since neither depends on hf-timestd.  hf-timestd's writer casts at its existing zstd step; its reader and every other reader decode through the codec.  Exports (Digital RF, MSQP WAVs) stay F32.

**Tech Stack:** Python 3.10+, numpy, zstandard, digital_rf 2.6.14, scipy (Welch PSD for the trial check), pytest.

**Spec:** `docs/superpowers/specs/2026-11-11-f16-archive-design.md` (approved by Michael 2026-11-11).  Evidence: `~/hamsci/tasks/f16-archive/` on the devbox (`finedetail.py` holds the trial measures).

## Global Constraints

- Scale: exactly `4096.0` (2¹²), a code constant, never a setting.  Encode: `(x * 4096).astype("<f2")` on the interleaved float32 view.  Decode: divide by the sidecar's `scale`.
- Sidecar keys for an F16 chunk: `"dtype": "complex-f16"`, `"scale": 4096.0`.  F32 chunks keep `"dtype": "complex64"` and gain no `scale`; a missing `scale` means 1.0.
- F16 applies only to zstd-compressed chunks (`.bin.zst`).  `.bin` and `.bin.lz4` stay complex64.
- Default stays F32 everywhere in the release that ships this.  hf-timestd setting: `[recorder] archive_dtype = "complex64" | "f16"`.  meteor-scatter setting: `[msqp] archive_dtype = "complex64" | "f16"`.
- Overflow: if any scaled component of a chunk would exceed 65504 in magnitude, the whole chunk stays complex64 and the writer logs one WARNING naming the chunk.  NaN and inf pass through unchanged.
- The RAM ring, radiod's stream and every live measurement stay F32.  No change to the T6 anomaly capture.
- Exports: `events/window_drf.py` writes complex64 Digital RF; MSQP packages and `msqp wav` write WAV (32-bit float I/Q, or the existing 16-bit audio derivation).
- Station configs change only through sigmond (`smd config`); each new key appears in its repo's config help/defaults so sigmond can set it.
- Tests: hf-timestd `uv run pytest`; hamsci-physics `uv run pytest`; meteor-scatter `uv run pytest`; sigmond `.venv/bin/python -m pytest`.

- station-web needs no change: `services/grape_service.py` skips `raw_buffer` and reads only GRAPE's own
  products (checked 2026-11-11).  The spec listed it; the audit cleared it.

### Task 1: hf-timestd I/Q codec

**Files:**
- Create: `src/hf_timestd/core/iq_codec.py`
- Test: `tests/test_iq_codec.py`

**Interfaces:**
- Produces:
  - `F16_SCALE: float = 4096.0`, `DTYPE_F32 = "complex64"`, `DTYPE_F16 = "complex-f16"`
  - `encode_f16(samples: np.ndarray) -> Optional[bytes]` — complex64 in; little-endian interleaved binary16 bytes out; `None` when any finite scaled component exceeds 65504.
  - `decode_iq(raw: bytes, dtype: str, scale: float = 1.0) -> np.ndarray` — complex64 out for either dtype; raises `ValueError` for an unknown dtype.
  - `bytes_per_sample(dtype: str) -> int` — 8 or 4.

- [ ] **Step 1: Write the failing tests**

```python
def test_roundtrip_error_far_below_signal():
    rng = np.random.default_rng(0)
    x = ((rng.standard_normal(240000) + 1j * rng.standard_normal(240000)) * 3.5e-6).astype(np.complex64)
    y = decode_iq(encode_f16(x), DTYPE_F16, F16_SCALE)
    assert y.dtype == np.complex64 and y.shape == x.shape
    sqnr = 10 * np.log10(np.sum(np.abs(x) ** 2) / np.sum(np.abs(x - y) ** 2))
    assert sqnr > 70.0

def test_overflow_returns_none():
    x = np.array([20.0 + 0j], dtype=np.complex64)          # 20 * 4096 > 65504
    assert encode_f16(x) is None

def test_nan_inf_pass_through():
    x = np.array([np.nan + 1j, np.inf + 0j, 1e-5 + 0j], dtype=np.complex64)
    y = decode_iq(encode_f16(x), DTYPE_F16, F16_SCALE)
    assert np.isnan(y[0].real) and np.isinf(y[1].real)

def test_decode_complex64_is_identity():
    x = np.arange(4, dtype=np.float32).view(np.complex64)
    assert np.array_equal(decode_iq(x.tobytes(), DTYPE_F32), x)

def test_unknown_dtype_raises():
    with pytest.raises(ValueError):
        decode_iq(b"\0" * 8, "int16")

def test_bytes_per_sample():
    assert bytes_per_sample(DTYPE_F32) == 8 and bytes_per_sample(DTYPE_F16) == 4
```
